# Aula 02 — Cores, fundos e bordas

- `color` altera a cor do texto e `background-color` define o fundo.
- `border` cria uma borda com espessura, estilo e cor.
- Classes permitem reutilizar o mesmo visual nas receitas.
- Use contraste suficiente entre texto e fundo para manter a leitura confortável.
