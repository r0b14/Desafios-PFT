# Aula 03 — Margin e padding

- `margin` cria espaço **fora** do elemento, separando-o dos demais.
- `padding` cria espaço **dentro** do elemento, entre o conteúdo e sua borda.
- `max-width` limita a largura do caderno e `margin: auto` o centraliza.
- Imagens responsivas usam `width: 100%` para não ultrapassar o cartão.
