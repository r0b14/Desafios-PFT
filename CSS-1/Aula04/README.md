# Aula 04 — Box Model

Todo elemento é formado por conteúdo, `padding`, `border` e `margin`.

- `box-sizing: border-box` inclui borda e preenchimento no tamanho definido.
- `padding` dá respiro ao conteúdo das seções.
- `margin` controla a distância entre as caixas.
- Bordas tornam os limites das áreas do layout visíveis.
