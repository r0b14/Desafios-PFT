# Aula 05 — Outline

- `outline` destaca um elemento sem ocupar espaço no Box Model.
- `outline-offset` afasta o contorno da borda, deixando o destaque mais visível.
- O desafio usa esse recurso nas imagens para chamar a atenção sem alterar o layout.
- Diferente de `border`, o `outline` não muda as dimensões do elemento.
