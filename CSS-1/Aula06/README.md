# Aula 06 — Texto e fontes

- `font-family` escolhe a fonte; fontes externas podem ser importadas do Google Fonts.
- `text-transform: uppercase` deixa os títulos em maiúsculas.
- `font-size` e `font-weight` criam hierarquia visual.
- `text-align` alinha o texto e `line-height` melhora a leitura dos parágrafos.
