# Aula 07 — Estrutura inicial

Use esta pasta como ponto de partida para o desafio da aula.

- Separe a estrutura em `index.html`, os estilos em `style.css` e comportamentos em `script.js`.
- Comece com seletores simples e classes com nomes claros.
- Teste cada mudança no navegador para entender seu efeito.
