# Aula 14 — Inline-block

## Resumo

`display: inline-block` permite deixar blocos lado a lado e, ao mesmo tempo, definir largura e margem.

## Parte técnica

- Cada `figure` usa `display: inline-block`.
- `width` define o tamanho dos cartões e imagens.
- `:hover` muda a opacidade ao passar o mouse.

## O que o miniprojeto atende

Galeria simples com três imagens de Pokémon, lado a lado, com legenda e efeito ao passar o mouse.
