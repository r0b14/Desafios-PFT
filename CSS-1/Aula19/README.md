# Aula 19 — Contadores CSS

## Resumo

Contadores CSS numeram elementos automaticamente, sem que os números precisem ser escritos no HTML.

## Parte técnica

- `counter-reset` cria ou reinicia um contador.
- `counter-increment` aumenta o contador em cada elemento.
- `content: counter(...)` mostra o número antes do texto.

## O que o miniprojeto atende

Blog simples com seções e listas numeradas automaticamente usando contadores CSS.
