# Aula 01 — Boas práticas de seletores

- Prefira **classes** para estilos reutilizáveis, como `.dica` ou `.botao`.
- Use nomes que expliquem a função do elemento, não apenas sua aparência.
- Evite seletores muito longos, pois eles deixam o CSS difícil de manter.
- `:hover` aplica estilo durante a interação com o mouse.
- Organize as regras para não precisar recorrer a `!important`.
