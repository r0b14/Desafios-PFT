5 boas práticas de seletores CSS

Seletores bem escolhidos deixam o código mais claro, fácil de manter e reaproveitar.

01

Prefira classes

Classes podem ser reutilizadas em vários elementos.

.botao { color: white; }
02

Seja específico

Escolha nomes que expliquem a função do elemento.

.card-receita { padding: 1rem; }
03

Evite seletores longos

Menos dependência da estrutura torna a alteração mais simples.

.menu a { text-decoration: none; }
04

Use estados

O seletor :hover mostra uma mudança ao passar o mouse.

.link:hover { color: tomato; }
05

Não use !important

Organize a cascata e a especificidade antes de recorrer a ele.

.aviso { background: gold; }
Pratique: dê nomes claros às classes e teste cada seletor no navegador.
