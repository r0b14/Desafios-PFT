# Aula 02 — Cores, fundo e bordas

- `color` altera a cor dos títulos e textos.
- `background` e `background-color` criam fundos para a página e os parágrafos.
- `border` combina largura, estilo e cor em uma única propriedade.
- `border-radius` arredonda os cantos e pode deixar os cartões mais suaves.
