# Aula 03 — Espaçamento

- `margin` controla a distância externa entre receitas, títulos e imagens.
- `padding` cria espaço interno no cartão e nos blocos de texto.
- `width: 100%` torna a imagem adaptável à largura disponível.
- `object-fit: cover` preserva um bom recorte quando uma imagem tem altura fixa.
