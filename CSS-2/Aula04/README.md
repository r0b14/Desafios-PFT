# Aula 04 — Box Model

O modelo de caixa é formado por conteúdo, `padding`, `border` e `margin`.

- `box-sizing: border-box` facilita o cálculo dos tamanhos.
- `padding` dá respiro ao conteúdo interno das seções.
- `margin` cria distância entre as caixas.
- Links externos devem usar `target="_blank"` junto com `rel="noopener"`.
