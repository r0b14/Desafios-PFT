# Aula 06 — Texto e fontes

- Google Fonts permite importar fontes com uma tag `<link>` no HTML.
- `font-family`, `font-size` e `font-weight` definem a aparência da tipografia.
- `text-transform: uppercase` deixa os títulos em maiúsculas.
- `text-align` e `line-height` aumentam a legibilidade dos parágrafos.
