# Aula 07 — Ícones e links

## Resumo do assunto

Ícones ajudam a representar uma ideia visualmente. Links levam o usuário para outra página ou site.

## Parte técnica

- Os ícones foram inseridos com Font Awesome.
- A tag `<a>` cria os links dos trailers.
- `:hover` altera a cor do link quando o mouse passa por ele.
- `display: inline-block` deixa os cartões lado a lado.

## O que o miniprojeto atende

Três filmes de gêneros diferentes, cada um com ícone, resumo e link para trailer.
