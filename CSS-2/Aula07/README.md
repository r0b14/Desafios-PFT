# Aula 07 — Ícones e links

- Ícones podem ser usados para representar visualmente o gênero dos filmes.
- Links usam `href`; `target="_blank"` abre o trailer em outra guia.
- `:hover` aplica uma mudança visual quando o mouse passa sobre links ou cartões.
- `transition` suaviza mudanças de cor e `transform` permite pequenos movimentos ou escalas.
