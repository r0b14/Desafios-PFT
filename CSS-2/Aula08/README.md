# Aula 08 — Menus e barras de navegação

## Resumo do assunto

Um menu reúne links que ajudam o usuário a navegar pela página.

## Parte técnica

- A tag `<nav>` identifica a área de navegação.
- Cada link usa `href="#id"` para levar até uma seção da mesma página.
- `display: inline-block` coloca os links do menu lado a lado.
- `:hover` destaca o link escolhido.

## O que o miniprojeto atende

Catálogo de filmes com menu no topo, três gêneros e dois filmes em cada seção.
