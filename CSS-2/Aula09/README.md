# Aula 09 — Tabelas estilizadas

## Resumo do assunto

Tabelas apresentam dados que possuem colunas e linhas relacionadas. Cabeçalhos explicam cada coluna e linhas alternadas facilitam a leitura.

## Parte técnica

- `table`, `thead`, `tbody`, `tr`, `th` e `td` dão estrutura semântica aos dados.
- `border-collapse: collapse` une as bordas das células.
- `tbody tr:nth-child(even)` seleciona linhas pares para aplicar uma cor alternativa.
- O contêiner com `overflow-x: auto` evita que tabelas largas quebrem no celular.

## O que o miniprojeto atende

Tabela com cabeçalho colorido e ícones, bordas em todas as células, linhas alternadas, espaçamento e cinco registros de funcionários.
