# Aula 10 — Display e max-width

## Resumo do assunto

`display` controla a forma como os elementos ocupam espaço. `max-width` define a largura máxima de um elemento.

## Parte técnica

- O `main` usa `max-width: 800px`, para não ficar muito largo.
- Cada receita usa `display: inline-block`, ficando ao lado das outras quando houver espaço.
- `vertical-align: top` alinha o topo dos cartões.

## O que o miniprojeto atende

Página de receitas com cabeçalho, link de navegação e cinco receitas.
