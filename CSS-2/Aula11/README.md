# Aula 11 — Position e z-index

## Resumo do assunto

`position` permite colocar elementos em um local específico. `z-index` define qual elemento fica na frente quando eles se sobrepõem.

## Parte técnica

- O `main` usa `position: relative`, tornando-se a referência dos outros elementos.
- A imagem, a descrição e o número usam `position: absolute`.
- Os valores de `z-index` mostram a ordem das camadas.

## O que o miniprojeto atende

Página simples da Chikorita com uma imagem e dois textos sobrepostos.
