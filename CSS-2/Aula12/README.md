# Aula 12 — Overflow

## Resumo do assunto

`overflow` define o que acontece quando o conteúdo não cabe dentro de uma caixa.

## Parte técnica

- `overflow: auto` cria uma barra de rolagem quando necessário.
- `overflow: hidden` esconde o conteúdo que ultrapassa a caixa.
- `overflow-x: auto` permite rolagem somente na horizontal.

## O que o miniprojeto atende

Três caixas simples que mostram os três comportamentos de overflow pedidos.
