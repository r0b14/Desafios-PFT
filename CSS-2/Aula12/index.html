Chikorita e overflow

overflow: auto

Chikorita é um Pokémon Planta. Esta caixa possui uma altura pequena. Quando há mais texto do que espaço, aparece uma barra de rolagem para que o conteúdo continue disponível. Assim, o texto não ultrapassa os limites da caixa.

overflow: hidden

Este texto é maior do que a caixa. Com overflow hidden, a parte que não cabe fica escondida e não aparece fora do elemento.

overflow-x: auto
