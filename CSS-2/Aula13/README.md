# Aula 13 — Float

## Resumo do assunto

`float` permite que o texto fique ao lado de uma imagem.

## Parte técnica

- `float: left` posiciona a imagem à esquerda.
- A margem separa a imagem do texto.
- `overflow: auto` na seção faz com que ela reconheça a altura da imagem flutuante.
