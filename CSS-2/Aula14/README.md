# Aula 14 — Inline-block

## Resumo do assunto

O valor `display: inline-block` combina o comportamento em linha (`inline`), permitindo que vários elementos fiquem lado a lado, com o comportamento de bloco (`block`), permitindo definir largura (`width`), altura (`height`), margens e preenchimentos.

## Parte técnica

- `display: inline-block` coloca elementos lado a lado respeitando suas dimensões.
- `vertical-align: top` alinha os blocos pelo topo para evitar desalinhamento com alturas diferentes.
- `width` e `height` são respeitados, diferente do `inline` comum.

## O que o miniprojeto atende

Galeria de cartões informativos de produtos alinhados lado a lado usando `inline-block`.
