# Aula 15 — Alinhamento

## Resumo do assunto

Alinhar elementos na tela é fundamental para criar interfaces organizadas. Combinamos `text-align`, margens automáticas (`margin: 0 auto`) e `vertical-align`.

## Parte técnica

- `text-align: center` centraliza textos e elementos inline dentro de um bloco.
- `margin: 0 auto` centraliza blocos com largura definida (`width`).
- `vertical-align: middle` alinha ícones e textos na linha média.

## O que o miniprojeto atende

Página com banner centralizado e seções alinhadas horizontal e verticalmente.
