# Aula 16 — Opacidade e Cores RGBA

## Resumo do assunto

`opacity` controla a transparência de um elemento e de todos os seus filhos. Já a função `rgba()` permite aplicar transparência apenas à cor de fundo, mantendo o texto nítido.

## Parte técnica

- `opacity: 0.5` deixa o elemento 50% transparente.
- `background-color: rgba(0, 0, 0, 0.6)` aplica fundo semitransparente sem afetar a opacidade do texto interno.
- Comparação direta entre os dois métodos.

## O que o miniprojeto atende

Cartões com sobreposições e comparação entre transparência geral e transparência de fundo.
