Opacidade e Transparência

Diferença entre a propriedade opacity e cores com canal alfa (rgba).

Elemento com opacity: 0.6

Atenção: todo o elemento fica transparente, incluindo este texto!

Elemento com background: rgba(30, 41, 59, 0.7)

Aqui, apenas o fundo é transparente. O texto permanece 100% legível e nítido!
