# Aula 17 — Pseudo-classes Interativas

## Resumo do assunto

Pseudo-classes representam o estado de um elemento quando o usuário interage com ele (como passar o mouse, clicar ou focar com o teclado).

## Parte técnica

- `:hover`: disparado quando o cursor do mouse está sobre o elemento.
- `:active`: disparado no momento exato do clique.
- `:focus`: disparado quando um campo ou botão recebe foco (ex.: via tecla Tab).
- `:focus-visible`: estilo de foco moderno para acessibilidade por teclado.

## O que o miniprojeto atende

Botões e campos interativos com resposta visual para hover, active e focus.
