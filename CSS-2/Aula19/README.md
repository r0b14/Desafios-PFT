# Aula 19 — Sombras (box-shadow e text-shadow)

## Resumo do assunto

Sombras criam profundidade e sensação de elevação nas páginas web. `box-shadow` projeta sombras nos contornos das caixas, enquanto `text-shadow` aplica sombras nas letras.

## Parte técnica

- Sintaxe do `box-shadow: x y desfoque espalhamento cor;`.
- Múltiplas sombras separadas por vírgula.
- Efeito suave com cores semitransparentes `rgba()`.
- `text-shadow` para dar destaque ou contraste em títulos.

## O que o miniprojeto atende

Cartões com efeito de elevação tridimensional suave ao passar o cursor do mouse.
