# Aula 20 — Bordas Arredondadas e Formas (border-radius)

## Resumo do assunto

`border-radius` define o arredondamento dos cantos de um elemento. Variando seus valores em pixels ou porcentagem, podemos criar desde cantos suaves até botões em formato de pílula e círculos perfeitos.

## Parte técnica

- `border-radius: 8px` arredonda todos os quatro cantos de forma uniforme.
- `border-radius: 9999px` cria o formato de "pílula" em botões.
- `border-radius: 50%` em elementos com mesma largura e altura resulta em um círculo perfeito.

## O que o miniprojeto atende

Galeria de componentes com diferentes estilos de arredondamento: cartão suave, botão pílula e avatar circular.
