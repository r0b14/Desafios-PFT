# Aula 21 — Gradientes CSS (linear e radial)

## Resumo do assunto

Gradientes são transições suaves entre duas ou mais cores. No CSS, são criados usando a propriedade `background-image` com funções como `linear-gradient()` e `radial-gradient()`.

## Parte técnica

- `linear-gradient(direcao, cor1, cor2)`: gradiente em linha reta (ex.: `to right`, `135deg`).
- `radial-gradient(circulo/elipse, cor1, cor2)`: gradiente que se expande do centro para fora.
- Paradas de cor com porcentagens para controlar onde a transição acontece.

## O que o miniprojeto atende

Cartões estilizados com fundos em gradiente linear moderno e gradiente radial centralizado.
