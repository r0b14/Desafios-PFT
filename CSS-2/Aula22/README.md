# Aula 22 — Transições Suaves (transition)

## Resumo do assunto

A propriedade `transition` permite alterar valores de propriedades CSS gradualmente ao longo do tempo (em vez de uma mudança brusca imediata) quando ocorre uma mudança de estado, como em um `:hover`.

## Parte técnica

- `transition-property`: propriedade que sofrerá a animação (ex.: `background-color`, `transform`).
- `transition-duration`: tempo que dura a transição (ex.: `0.3s`).
- `transition-timing-function`: curva de aceleração (ex.: `ease`, `linear`).
- Atalho: `transition: all 0.3s ease;`.

## O que o miniprojeto atende

Botões e cartões com mudanças de cor, tamanho e sombra animadas suavemente.
