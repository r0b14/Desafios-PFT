# Aula 23 — Transformações 2D (transform)

## Resumo do assunto

A propriedade `transform` permite modificar o formato, tamanho e posição de um elemento visualmente sem interferir no fluxo normal dos outros elementos da página.

## Parte técnica

- `translate(x, y)`: move o elemento no eixo horizontal ou vertical.
- `scale(fator)`: redimensiona o elemento proporcionalmente (ex.: `scale(1.2)` aumenta 20%).
- `rotate(angulo)`: gira o elemento (ex.: `rotate(45deg)`).
- Pode combinar múltiplas transformações: `transform: rotate(10deg) scale(1.1);`.

## O que o miniprojeto atende

Cartões interativos demonstrando rotação, escala e translação em duas dimensões.
