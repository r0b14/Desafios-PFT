# Aula 24 — Introdução ao Flexbox (Container e Direção)

## Resumo do assunto

O Flexbox (*Flexible Box Layout*) é um modelo de layout unidimensional criado para distribuir espaço entre itens e alinhar conteúdo de forma simples e previsível.

## Parte técnica

- `display: flex` transforma o elemento pai em um container flexível.
- `flex-direction: row` (padrão): organiza os itens em linha horizontal.
- `flex-direction: column`: organiza os itens em coluna vertical.
- `flex-direction: row-reverse` e `column-reverse`: invertem a ordem dos itens.

## O que o miniprojeto atende

Barra de navegação e lista de cartões demonstrando a alteração da direção dos eixos flexíveis.
