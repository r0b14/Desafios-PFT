# Aula 25 — Flexbox: Alinhamento e Espaçamento (justify-content e align-items)

## Resumo do assunto

O Flexbox oferece propriedades poderosas para alinhar itens ao longo do eixo principal (`justify-content`) e do eixo cruzado (`align-items`), além de definir espaçamento direto com `gap`.

## Parte técnica

- `justify-content`: alinha no eixo principal (`center`, `space-between`, `space-around`, `flex-end`).
- `align-items`: alinha no eixo perpendicular (`center`, `flex-start`, `flex-end`, `stretch`).
- `gap`: define espaçamento limpo entre os filhos sem precisar de margens manuais.

## O que o miniprojeto atende

Barra de cabeçalho completa (logo à esquerda, links centralizados e botão de perfil à direita) criada com `space-between` e `align-items: center`.
