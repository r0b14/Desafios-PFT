# Aula 26 — Flexbox: Quebra de Linha e Ordem (flex-wrap e order)

## Resumo do assunto

Por padrão, o Flexbox tenta encaixar todos os itens na mesma linha. Com `flex-wrap: wrap`, permitimos que os itens quebrem para a linha seguinte quando não houver espaço suficiente. A propriedade `order` permite reorganizar visualmente os elementos.

## Parte técnica

- `flex-wrap: wrap`: permite a quebra automática em múltiplas linhas.
- `order: -1` ou `order: 2`: altera a ordem visual do elemento sem alterar o HTML.
- Criação de galerias flexíveis adaptáveis a diferentes larguras de tela.

## O que o miniprojeto atende

Galeria de fotos/cartões que quebra em várias linhas automaticamente conforme a largura da tela.
