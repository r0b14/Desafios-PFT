# Aula 28 — Introdução ao CSS Grid (Linhas e Colunas)

## Resumo do assunto

O CSS Grid é o sistema de layout bidimensional nativo mais poderoso da web. Ele permite organizar elementos em linhas e colunas simultaneamente.

## Parte técnica

- `display: grid`: ativa o contexto de grid no elemento pai.
- `grid-template-columns`: define a quantidade e largura das colunas (ex.: `200px 200px`).
- `grid-template-rows`: define a altura das linhas.
- O grid posiciona os filhos automaticamente dentro das células formadas.

## O que o miniprojeto atende

Grade regular de 3 colunas para apresentação de cursos ou serviços.
