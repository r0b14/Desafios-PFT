# Aula 30 — CSS Grid: Áreas Nomeadas (grid-template-areas)

## Resumo do assunto

`grid-template-areas` permite "desenhar" o layout visual da página usando palavras que representam cada região, como cabeçalho, menu lateral, conteúdo e rodapé.

## Parte técnica

- `grid-template-areas`: mapeia as áreas da página em uma matriz visual de texto.
- `grid-area`: propriedade aplicada aos filhos que associa cada elemento à sua área nomeada.
- Código altamente legível que reflete o mapa visual do site.

## O que o miniprojeto atende

Estrutura completa de página com cabeçalho, barra lateral, artigo principal e rodapé organizada por áreas nomeadas.
