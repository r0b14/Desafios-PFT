# Aula 34 — Media Queries (Breakpoints)

## Resumo do assunto

As *Media Queries* são o pilar do design responsivo. Elas permitem aplicar regras de estilo específicas com base nas características do dispositivo, principalmente a largura da tela (`max-width` ou `min-width`).

## Parte técnica

- `@media (max-width: 600px)`: aplica estilos quando a tela tiver no máximo 600px (celulares).
- Alteração de `flex-direction: row` para `flex-direction: column`.
- Ajuste de tamanho de fontes e margens em telas menores.

## O que o miniprojeto atende

Layout de duas colunas que se empilha automaticamente em uma coluna única em telas de celular.
