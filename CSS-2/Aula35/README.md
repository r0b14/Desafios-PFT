# Aula 35 — Design Responsivo (Conceito Mobile-First)

## Resumo do assunto

*Mobile-First* é a prática de projetar e programar uma página pensando primeiro na experiência em celulares (telas pequenas) e, em seguida, adicionar recursos e colunas para telas maiores usando `min-width`.

## Parte técnica

- Estilos padrão sem media queries focados em telas verticais (mobile).
- `@media (min-width: 640px)` para adicionar visualizações de tablet.
- `@media (min-width: 1024px)` para computadores e monitores largos.
- Melhora o desempenho e simplifica a manutenção do código CSS.

## O que o miniprojeto atende

Estrutura de menu e lista de destaques construída com a abordagem Mobile-First.
