# Aula 37 — Animações Contínuas (Spinners e Efeito Pulso)

## Resumo do assunto

Com `animation-iteration-count: infinite`, uma animação nunca para. Essa técnica é muito usada para criar indicadores de carregamento (*spinners*) e botões de alerta que pulsam.

## Parte técnica

- `animation-iteration-count: infinite`: repetição contínua.
- `animation-timing-function: linear`: rotação sem aceleração constante.
- `animation-direction: alternate`: vai e volta suavemente.

## O que o miniprojeto atende

Indicador circular de carregamento (*spinner*) e botão pulsante de notificação.
