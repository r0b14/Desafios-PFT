# Aula 40 — Projeto Integrador CSS: Landing Page Responsiva

## Resumo do assunto

Projeto final de consolidação de toda a trilha CSS-2: criação de uma página inicial (*Landing Page*) completa, integrando variáveis CSS, Flexbox, CSS Grid, media queries, transições e boas práticas visuais.

## Conceitos integrados

- **Variáveis CSS**: paleta de cores centralizada no `:root`.
- **Flexbox**: cabeçalho e navegação alinhados com `justify-content: space-between`.
- **CSS Grid**: grade de cartões de serviços e benefícios com `repeat()` e `gap`.
- **Media Queries**: adaptação para smartphones e telas maiores (Mobile-First).
- **Interatividade**: efeitos suaves de hover em botões e cartões.

## O que o miniprojeto atende

Página de apresentação moderna, acessível, responsiva e bem estruturada para o programa Florescendo Talentos.
