# CSS-2 — Miniprojetos

Cada aula pode ser aberta diretamente no navegador pelo arquivo `index.html`.

| Aula | Projeto                | Conceitos praticados                    |
| ---- | ---------------------- | --------------------------------------- |
| 01   | Infográfico CSS        | Seletores e boas práticas               |
| 02   | Receitas coloridas     | Cores, fundo e bordas                   |
| 03   | Caderno de receitas    | `margin` e `padding`                    |
| 04   | Biografia              | Box Model e `box-sizing`                |
| 05   | Receitas em destaque   | `outline`                               |
| 06   | Receitas com estilo    | Texto e fontes                          |
| 07   | Catálogo de filmes     | Ícones, links e `:hover`                |
| 08   | Catálogo com menus     | Listas, navegação e dropdown            |
| 09   | Quadro de funcionários | Tabelas e `nth-child`                   |
| 10   | Receitas da Casa       | `display` e `max-width`                 |
| 11   | Pokédex Chikorita      | `position` e `z-index`                  |
| 12   | Chikorita e overflow   | `overflow`, `overflow-x` e `overflow-y` |
| 13   | Perfil de Chikorita    | `float` e `clear`                       |
