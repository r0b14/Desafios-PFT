# CSS-2 — Miniprojetos

Cada aula pode ser aberta diretamente no navegador pelo arquivo `index.html`.

| Aula | Projeto | Conceitos praticados |
| --- | --- | --- |

| 04 | Biografia | Box Model e `box-sizing` |
| 05 | Receitas em destaque | `outline` |
| 06 | Receitas com estilo | Texto e fontes |
| 07 | Catálogo de filmes | Ícones, links e `:hover` |
