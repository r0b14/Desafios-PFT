# Aula 33 — `throw` e `instanceof`

- `throw new RangeError(mensagem)` lança uma exceção adequada para valor fora de um limite aceito.
- `throw new TypeError(mensagem)` indica que a entrada possui tipo ou formato incorreto.
- `instanceof` verifica a classe do erro e permite respostas específicas no `catch`.
- `Math.sqrt()` calcula a raiz; a validação ocorre antes do cálculo.
