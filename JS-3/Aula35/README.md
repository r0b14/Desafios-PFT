# Aula 35 — Boas práticas de código

- Use nomes descritivos, como `pontuacaoInicial`, em vez de nomes genéricos como `x`.
- Mantenha uma indentação consistente para revelar blocos e condições.
- Separe ideias em linhas e funções pequenas para facilitar a leitura.
- Reduza aninhamentos retornando cedo quando uma condição inválida for encontrada.
- Prefira `const`; use `let` somente quando o valor precisar mudar.
