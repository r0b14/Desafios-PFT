Revisor de código

Compare o exemplo problemático com uma versão mais legível e organizada.

Antes

let x=10
function calc(a,b){if(a>0){return a+b}else{return 0}}

Depois

const pontuacaoInicial = 10;

function calcularSoma(valorA, valorB) {
  if (valorA <= 0) return 0;
  return valorA + valorB;
}
  • Nomes claros explicam o propósito de variáveis e funções.
  • Indentação e espaços deixam a estrutura visível.
  • Evitar aninhamento excessivo torna a leitura mais simples.
  • const é usado quando a variável não será reatribuída.
