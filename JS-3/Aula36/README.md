# Aula 36 — Redução de complexidade

Esta calculadora separa cada responsabilidade em partes simples.

- **Arrow functions:** `const somar = (a, b) => a + b` cria funções curtas para cada operação.
- **`switch`:** escolhe qual operação chamar conforme o valor selecionado.
- **Operador ternário:** testa uma condição em forma compacta: `condicao ? valorSeVerdadeiro : valorSeFalso`.
- `Number()` converte os valores dos campos, que chegam como texto, para números.
