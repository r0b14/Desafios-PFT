# Aula 37 — Prettier e ESLint

- **Prettier** formata automaticamente o código: espaçamento, quebras de linha e indentação ficam consistentes.
- **ESLint** analisa o JavaScript e avisa sobre problemas, como variáveis não usadas e padrões arriscados.
- Essas ferramentas não substituem a lógica: elas ajudam a deixar o código mais legível e a encontrar erros cedo.
- No VS Code, instale as extensões, configure o Prettier como formatador padrão e use `Format Document` para aplicar a formatação.
