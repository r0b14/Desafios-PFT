# Aula 39 — Promises e async/await

## Resumo

Uma Promise representa uma tarefa que pode terminar com sucesso ou erro. `async` e `await` deixam esse fluxo mais parecido com código comum.

## Parte técnica

- `new Promise` cria a busca simulada.
- `resolve` informa que o produto foi encontrado.
- `reject` informa que a busca falhou.
- `await` espera a Promise terminar e `try/catch` trata os dois resultados.

## O que o miniprojeto atende

Busca de produto em catálogo usando Promise, `resolve`, `reject` e `async/await`.
