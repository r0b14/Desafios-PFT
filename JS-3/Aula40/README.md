# Aula 40 — then, catch e finally

## Resumo

Depois de criar uma Promise, podemos tratar seu resultado com métodos encadeados.

## Parte técnica

- `.then()` executa quando a Promise usa `resolve`.
- `.catch()` executa quando a Promise usa `reject`.
- `.finally()` sempre executa ao fim da operação, com sucesso ou falha.

## O que o miniprojeto atende

Simulação de envio de pedido que mostra os dois resultados possíveis de uma Promise.
