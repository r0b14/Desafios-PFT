# Aula 41 — Promises e async/await

## Resumo

Promises representam tarefas que terminam no futuro. `async` e `await` deixam o código assíncrono mais fácil de ler.

## Parte técnica

- `aguardar` simula uma operação demorada usando `Promise` e `setTimeout`.
- `adicionarTarefa` e `removerTarefa` esperam a operação terminar com `await`.
- `mostrarTarefas` atualiza a lista exibida na página.

## O que o miniprojeto atende

Gerenciador básico que adiciona e remove tarefas de forma assíncrona.
