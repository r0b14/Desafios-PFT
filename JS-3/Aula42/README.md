# Aula 42 — Métodos HTTP

## Resumo

APIs REST usam métodos HTTP para indicar qual ação será realizada em um recurso.

## Parte técnica

- `GET` consulta dados.
- `POST` cria dados.
- `PUT` atualiza dados.
- `DELETE` remove dados.

## O que o miniprojeto atende

Simulador de requisições para a Swagger Petstore. Ele não altera a API real: apresenta exemplos seguros de cada endpoint.
