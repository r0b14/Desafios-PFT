# Aula 43 — fetch e GET

## Resumo

`fetch` permite buscar dados em uma API. Uma requisição GET consulta informações sem modificá-las.

## Parte técnica

- `fetch(url)` faz a requisição para a PokéAPI.
- `response.ok` confirma se a busca funcionou.
- `response.json()` converte a resposta da API em objeto JavaScript.
- `try/catch` exibe uma mensagem quando há erro.

## O que o miniprojeto atende

Busca de dados de um Pokémon específico usando requisição GET e `fetch`.
