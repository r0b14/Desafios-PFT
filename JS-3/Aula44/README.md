# Aula 44 — Listas com fetch

> O enunciado da Aula 44 não veio nos anexos. Este projeto continua o assunto de `fetch` da Aula 43.

## Parte técnica

- A URL usa `limit=5` para pedir somente cinco Pokémon.
- `forEach` percorre os resultados recebidos.
- Cada resultado é transformado em um item de lista no HTML.

## O que o miniprojeto apresenta

Uma lista de Pokémon carregada pela PokéAPI com `fetch` e `async/await`.
