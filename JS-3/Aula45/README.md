# Aula 45 — URL e FormData

## Resumo

O objeto `URL` ajuda a montar endereços com parâmetros. `FormData` coleta os valores de um formulário.

## Parte técnica

- `new FormData(formulario)` lê os campos do formulário.
- `new URL(...)` cria uma URL manipulável.
- `searchParams.set` adiciona parâmetros para uma requisição GET.
- A página busca posts da API JSONPlaceholder.

## O que o miniprojeto atende

Formulário que usa `FormData`, monta uma URL com parâmetros e busca posts com `fetch`.
