# Aula 46 — Classes e objetos

## Resumo

Uma classe é um modelo usado para criar objetos. Atributos guardam dados, métodos representam ações e instâncias são objetos criados a partir da classe.

## Parte técnica

- `Caderno` e `Caneta` possuem três atributos e três métodos cada.
- São criadas duas instâncias de cada classe.
- Métodos modificam atributos e outros exibem os valores modificados.

## O que o miniprojeto atende

Representação de objetos de sala de aula com classes, atributos, métodos e instâncias.
