# Aula 47 — Herança

## Resumo

Herança permite criar classes mais específicas a partir de uma classe base. As classes derivadas recebem atributos e métodos da classe base.

## Parte técnica

- `Pessoa` é a classe base.
- `Estudante` e `Professor` usam `extends Pessoa`.
- `super(...)` chama o construtor da classe base.
- Cada classe derivada possui três atributos e três métodos próprios.

## O que o miniprojeto atende

Duas instâncias de Estudante e duas de Professor, com métodos herdados e específicos.
