# Aula 48 — Manipulação de strings

## Resumo

Strings podem ser pesquisadas, recortadas e substituídas por métodos próprios do JavaScript.

## Parte técnica

- `indexOf` encontra a posição de uma palavra.
- `slice` extrai uma parte da frase.
- `replaceAll` troca todas as ocorrências de uma palavra.

## O que o miniprojeto atende

Classe Poema com um atributo e três métodos para analisar uma frase.
