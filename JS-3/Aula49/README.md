# Aula 49 — split, join e replace

## Resumo

Uma string pode ser separada em partes, modificada e unida novamente em outro formato.

## Parte técnica

- `replaceAll` troca `_` e `.` por `-`.
- `split('-')` divide a data em dia, mês e ano.
- `join('/')` une as partes no formato final.

## O que o miniprojeto atende

Função que recebe uma data em formatos diferentes e devolve sempre `DD/MM/AAAA`.
