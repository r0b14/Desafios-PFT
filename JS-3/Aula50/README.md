# Aula 50 — Comparação de strings

## Resumo

Strings podem ser comparadas pelo conteúdo ou pelo tamanho. Antes disso, é útil remover espaços e padronizar letras maiúsculas e minúsculas.

## Parte técnica

- `trim()` remove espaços no início e no fim.
- `toLowerCase()` deixa a comparação independente de maiúsculas e minúsculas.
- `===` compara o conteúdo e `.length` compara o tamanho.

## O que o miniprojeto atende

Função que compara duas strings pelo método escolhido e retorna `true` ou `false`.
