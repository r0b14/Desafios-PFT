# Aula 59 — Miniprojeto: Paradigmas de Programação em JavaScript

## Descrição do desafio

Para compreender como diferentes estilos de desenvolvimento coexistem no JavaScript, este miniprojeto explora e compara os três principais paradigmas de programação: **Imperativo**, **Funcional** e **Orientado a Objetos (OO)**.

## As 3 ferramentas escolhidas para cada paradigma

### 1. Paradigma Imperativo (Foco no "como fazer", passo a passo, controle de fluxo e estado mutável)
- `for`: laço de repetição tradicional que controla manualmente o índice e os passos.
- `if`: estrutura condicional de decisão e bifurcação de fluxo.
- `let` (mutação de variável): acumulação manual de valores em uma variável cujo valor é alterado a cada iteração.

### 2. Paradigma Funcional (Foco no "o que fazer", imutabilidade e funções de alta ordem)
- `map()`: transformação pura de cada elemento gerando um novo array sem modificar o original.
- `filter()`: seleção declarativa de itens com base em um predicado.
- `reduce()`: redução e agregação de dados em um resultado único.

### 3. Paradigma Orientado a Objetos (Foco em modelagem do mundo real com dados e comportamentos encapsulados)
- `class`: modelo estrutural para instanciar objetos.
- `constructor`: método especial para inicializar os atributos do objeto.
- `this`: referência interna à própria instância do objeto e seus métodos.

## O problema resolvido pelos 3 paradigmas

Processar uma lista de compras de supermercado: aplicar um desconto de 10% nos itens acima de R$ 50,00 e calcular o total final a pagar. A página exibe a implementação detalhada e comentada nas três abordagens para comparação visual.
