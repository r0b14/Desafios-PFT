# Aula 60 — Projeto Integrador: CRUD com persistência

## Resumo

Projeto de consolidação da trilha JavaScript 3: construção de um gerenciador completo com as quatro operações básicas (Criar, Ler, Atualizar e Deletar), integrado com `localStorage` e renderização reativa no DOM.

## Parte técnica

- **Create**: inserção de novas tarefas com validação de dados e ID único.
- **Read**: leitura e exibição ordenada a partir do `localStorage`.
- **Update**: alternância de estado (pendente / concluída) persistida imediatamente.
- **Delete**: exclusão de itens específicos com atualização reativa do DOM.
- Totalizadores dinâmicos e filtros rápidos de exibição.

## O que o miniprojeto atende

Aplicação interativa de lista de tarefas e metas com persistência local, filtros de status e remoção individual.
