---- Miniprojeto 04

Bem-vindos ao Miniprojeto da nossa Aula 04! 

Neste projeto, você terá a oportunidade de colocar em prática suas habilidades de formatação de texto e hierarquização de conteúdo em HTML, aplicando operações básicas de formatação e estruturação de cabeçalhos. Este desafio incentiva também a realização de práticas efetivas de formatação e estruturação.

Imagine que você está criando uma página de receitas. Sua tarefa será desenvolver uma página HTML que utilize tags básicas e estruturadas para organizar o conteúdo de forma clara e acessível. Em pelo menos uma parte do projeto, você deverá demonstrar o uso efetivo das tags de formatação e cabeçalhos.

Depois de desenvolver a página, teste sua visualização em um navegador para garantir que está funcionando corretamente. Este é o momento perfeito para você demonstrar suas habilidades em HTML e criar uma solução dinâmica e eficiente. Ao concluir este miniprojeto, você terá reforçado seu entendimento sobre como trabalhar com HTML em diferentes contextos e estará mais preparado(a) para aplicar essas técnicas em projetos reais. Mãos à obra, você consegue!

Objetivo
Desenvolver habilidades para formatar texto em HTML utilizando tags de formatação básica e hierarquizar o conteúdo com cabeçalhos apropriados.

Descrição
Os alunos irão praticar a formatação de texto e a hierarquização de conteúdo em uma página HTML simples, utilizando tags básicas. Eles criarão uma estrutura básica de página que incorpora títulos, parágrafos e formatações textuais.

Habilidade:
Compreender e aplicar tags básicas de formatação em HTML.
Hierarquizar o conteúdo utilizando cabeçalhos apropriados.

Etapas:
Formação dos Grupos e Introdução às Tags Básicas:
a. Divida a turma em grupos de 3 a 4 alunos 

Prática de Criação de uma Página HTML
a. Para exemplificar, utilize uma página de receitas como caso real. O site https://www.minhareceita.com.br/receita/bolo-de-chocolate-com-morango/ pode servir como inspiração. Observe como os cabeçalhos são usados para organizar informações sobre a receita, e como o texto é formatado para destacar ingredientes e passos.
b. Os alunos devem criar um novo arquivo HTML com a estrutura básica, seguindo o exemplo da página de receitas:
    i. Inicie com a declaração do tipo de documento e as tags <html>, <head>, e <body>.
    ii. Dentro do <head>, inclua um <title> para a página.
    iii. No <body>, os alunos devem:
      1. Adicionar um título principal usando <h1> (ex: "Receita de Bolo de Chocolate").
      2. Incluir subtítulos com <h2> e <h3> (ex: "Ingredientes" e "Modo de Preparo").
      3. Criar parágrafos com <p> para listar ingredientes e passos.
      4.Usar tags de formatação como <b>, <i>, <u>, e <strong> para destacar informações.


---- Miniprojeto 05

Bem-vindos ao Miniprojeto da Aula 05!

Este é um momento crucial para você aplicar seus conhecimentos de HTML na criação de um currículo digital completo. Você vai estruturar um currículo que inclui informações pessoais, formação acadêmica e habilidades, usando uma variedade de elementos HTML.

Durante o projeto, você vai praticar a utilização de listas para organizar informações, cabeçalhos para seções claras, e tabelas para detalhar experiências ou educação. Esta é a oportunidade perfeita para demonstrar suas habilidades de desenvolvimento web e criar um currículo que poderia ser usado no mundo real.

Objetivo
Desenvolver habilidades para criar um currículo em HTML utilizando tags e elementos básicos, focando na apresentação de informações pessoais, formação acadêmica e habilidades.

Descrição
Os alunos irão criar um currículo online que destaca suas informações pessoais, formação acadêmica e habilidades. O currículo deve ser visualmente claro e organizado, utilizando listas e tabelas para estruturar as informações. Essa atividade permitirá que os alunos aprendam a utilizar HTML de forma prática e significativa, mesmo sem experiência profissional.

Habilidade
Compreender e aplicar as tags <h1>, <h2>, <p>, <ul>, <ol>, <table>, <tr>, <td>, e <th> em HTML.
Estruturar informações de forma organizada utilizando listas e tabelas.

Etapas
Formação dos Grupos e Introdução às Tags Básicas:
a. Divida a turma em grupos de 3 a 4 alunos.
b. Os alunos podem criar um personagem fictício para desenvolver o currículo ou optar por escolher um colega da turma.
Estruturação da Página HTML: 
a. Os alunos devem criar um novo arquivo HTML seguindo as instruções abaixo:
   i. Inicie com a declaração do tipo de documento e as tags <html>, <head>, e <body>.
   ii. Dentro do <head>, inclua um <title> para a página (ex: "Currículo de [Nome do Aluno]").
   iii. No <body>, os alunos devem:
Adicionar um título principal usando <h1> (ex: "Currículo de [Nome do Aluno]").
Criar uma seção para informações pessoais com <h2> e utilizar <p> para descrever dados como nome, endereço e e-mail.
Criar uma seção de formação acadêmica usando uma lista ordenada (<ol>) para listar os cursos e instituições.
Criar uma seção de habilidades utilizando uma lista não ordenada (<ul>) para destacar as habilidades e competências.
Incluir uma tabela usando <table> para apresentar cursos relevantes ou projetos, utilizando as tags <tr>, <td>, e <th>.


---- Miniprojeto 06

Bem-vindos ao Miniprojeto da Aula 06! 

Hoje, você terá a chance de aplicar seus conhecimentos na criação de uma página biográfica interativa. Este projeto envolverá o uso de listas e links para conectar a biografia a recursos externos e internos, como artigos, vídeos e músicas, enriquecendo o conteúdo e a experiência do usuário.

Vocês irão desenvolver um site que não só conta a história de uma pessoa, mas também oferece um portal para o mundo dessa pessoa através de links. Este é um excelente exercício para consolidar suas habilidades em HTML e prepará-lo para projetos mais complexos.

Objetivo: Desenvolver habilidades para criar uma página biográfica em HTML, incluindo uma lista de arquivos e links de interesse, como artigos, vídeos, músicas e livros favoritos. O foco será no uso correto de listas e links (<a>) para melhorar a interatividade e navegação.


Descrição: Nesta atividade, os alunos vão criar uma página de biografia fictícia ou real que inclua uma lista de arquivos e conteúdos de interesse. A biografia pode incluir links para vídeos, músicas, livros, ou artigos que o autor fictício gosta ou recomenda. Os alunos devem organizar as informações usando listas ordenadas e não ordenadas, além de links que redirecionem para páginas da web, criando uma experiência rica em conteúdo e interativa.

Habilidade:

Utilizar a tag <a> para criar links externos para páginas e recursos online.
Criar links internos para facilitar a navegação dentro do documento HTML.
Organizar o conteúdo de forma clara e esteticamente agradável.

Etapas:
Revisão e Expansão da Estrutura HTML:

a. Divida a turma em grupos de 3 a 4 alunos.
b. Discuta como serão a estrutura básica que irão inserir os links de forma significativa. Os links podem ser de um vídeo favorito, jogo online, blog ou site de notícias, livro, música, etc.
Adicionando Links:
a. Criação da Página:
    i. Os alunos devem desenvolver um novo arquivo HTML que representa a biografia de um personagem fictício ou real. A biografia deve incluir, no mínimo, as seguintes informações:

Nome e idade do personagem.
Uma lista com pelo menos 6 itens de interesse, como hobbies, livros favoritos, filmes, músicas ou vídeos.
Os alunos devem escolher 3 desses links e alterar o atributo target para "_blank", garantindo que ao clicar, os links sejam abertos em novas abas. Após implementar essa funcionalidade, devem validar o comportamento para verificar se os links estão funcionando corretamente.

b. índice de Navegação:

       i. Os alunos devem criar um índice de navegação no topo da página que permita redirecionar para diferentes seções da biografia, incluindo um link que leva diretamente para a lista de itens de interesse. Isso facilitará a navegação e tornará a página mais interativa e amigável para o usuário.

       ii. Lembre-se de que, para criar um índice de navegação eficaz, é essencial estabelecer relacionamentos entre as tags usando o atributo href e o atributo id.

---- Miniprojeto 08
Bem-vindos ao Miniprojeto da Aula 08! 
Neste projeto prático, você terá a oportunidade de aplicar o que aprendeu sobre SVG criando um gráfico de barras para visualizar dados de forma dinâmica e interativa. Este projeto não apenas reforçará seu entendimento de SVG, mas também demonstrará como gráficos vetoriais podem ser poderosas ferramentas de visualização de dados.

Prepare-se para criar, experimentar e aprender a melhor forma de apresentar informações de maneira clara e visualmente atraente.

Objetivo:
Desenvolver habilidades para criar gráficos vetoriais simples utilizando SVG, inserindo-os em páginas HTML.

Descrição:
Os alunos criarão um pequeno dashboard online, utilizando SVG para representar em um gráfico de barras dados de alguma pesquisa. Eles aprenderão a criar formas básicas, aplicar cores, e inserir esses gráficos em uma página HTML.

Habilidade:

Compreender os conceitos básicos de SVG.
Criar formas geométricas simples utilizando elementos SVG.
Aplicar cores e gradientes em elementos SVG.
Inserir SVGs em uma página HTML

Etapas: 

1. Formação dos Grupos e Introdução às Tags Básicas:
a. Divida a turma em grupos de 3 a 4 alunos

2. Criando Gráficos SVG:
a. Cada grupo escolherá um tema de pesquisa e criará um gráfico de barras em SVG para representar os dados coletados.

    i. Definir um tema: Escolher um assunto de interesse comum, como "Jogos mais populares", "Horas de sono por dia", “Quantidade de dias que pratica exercício”, etc

x: Posição horizontal do retângulo 
y: Posição vertical do retângulo 
width: Largura da barra (deve ser constante para todas as barras).
height: Altura da barra (proporcional ao valor do dado).
fill: Cor da barra (pode ser escolhida).

----- Miniprojeto 10

Bem-vindos ao Miniprojeto da Aula 10! 
Este projeto é uma oportunidade excelente para aplicar os conceitos aprendidos sobre eventos em JavaScript. Você criará uma interface simples de um mini banco, onde eventos como cliques e hovers serão usados para adicionar interatividade sem depender de CSS.

Este miniprojeto não apenas reforçará seu entendimento sobre eventos, mas também permitirá que você pratique a manipulação do DOM e a criação de páginas web que respondem às ações do usuário de maneira eficiente e intuitiva.

Objetivo
Ensinar os alunos a implementar eventos em um site de mini banco, onde eles poderão adicionar dinheiro à conta através de um evento de clique e mostrar ou ocultar o saldo usando um evento de hover, sem a necessidade de CSS.

Descrição 
O projeto consiste em criar uma interface simples de um mini banco, permitindo que os usuários adicionem dinheiro à sua conta e visualizem seu saldo de forma interativa. Os alunos aprenderão a manipular eventos de clique e hover em JavaScript.

Habilidade:

Compreender a manipulação de eventos em JavaScript.
Implementar eventos de clique para ações de adicionar dinheiro.
Usar eventos de hover para exibir ou ocultar informações (saldo da conta).

Etapas: 

1. Formação dos Grupos e Introdução ao HTML Básico:
a. Divida a turma em grupos de 3 a 4 alunos

2. Construir o Mini Banco:
Passo 1: Criar a Estrutura de Arquivos

1. Crie uma pasta para o projeto:
    i. Nomeie essa pasta como mini-banco.
    ii. Esse será o diretório onde você colocará todos os arquivos do projeto.

2. Dentro dessa pasta, crie dois arquivos:
    i. index.html: Esse será o arquivo principal que contém a estrutura HTML.
    ii. script.js: Esse será o arquivo de JavaScript, onde você adicionará as funcionalidades de clique e hover.

3. Abra o arquivo index.html em seu editor de texto.

Passo 2: Criar a Estrutura HTML

1. Inicie a estrutura básica do HTML:

- O HTML é a base de qualquer página da web. - Adicione um título e uma saudação dentro da tag <body>:
i. Para personalizar o seu mini banco, adicione um título para dar boas-vindas ao usuário.

-Crie um formulário para adicionar dinheiro:
i. Agora, crie um formulário que permitirá ao usuário adicionar dinheiro. O formulário incluirá um campo para o valor e um botão para submeter esse valor.
       ii. O campo <input type="number"> permite que o usuário digite apenas números (como o valor a ser adicionado à conta).
       iii. O atributo min="1" garante que o valor mínimo inserido seja 1.
       iv. O botão de envio (submit) acionará o evento de adicionar dinheiro.

- Adicione um campo para exibir o saldo: 
i. Crie uma área na página onde o saldo será exibido. Aqui, o saldo começará em R$ 0,00.
       ii. O saldo será atualizado sempre que o usuário adicionar dinheiro.
       iii. O elemento <span> conterá o valor atual do saldo.
      iv. O parágrafo <p id="mensagem-hover"> será usado para exibir uma mensagem quando o usuário passar o mouse sobre o saldo.

Passo 3: Adicionar a Lógica com JavaScript
1. Abra o arquivo script.js no editor de texto.

2. Identifique os elementos HTML que você manipulou:
Para interagir com os elementos HTML, você precisa selecioná-los no JavaScript usando seus IDs. Isso permitirá que o JavaScript atualize o valor do saldo e manipule o formulário.
Crie uma variável para armazenar o saldo inicial:
O saldo começará em 0. Use uma variável para guardar esse valor.

3. Adicione um evento de clique (submit) ao formulário:
- Quando o usuário clicar no botão de "Adicionar", o JavaScript precisa pegar o valor digitado e atualizar o saldo. Para isso, você usará o evento submit.- O evento submit ocorre quando o formulário é enviado, e nele você evitará o comportamento padrão (recarregar a página).

     i. O event.preventDefault() impede que o formulário faça o envio padrão e recarregue a página.
     ii. O valor digitado no campo é capturado e convertido para um número com parseFloat.
     iii. Se o valor for válido, ele é adicionado ao saldo, e o saldo exibido é atualizado.

4. Adicione eventos de hover para exibir uma mensagem:
Agora, adicione eventos de mouseenter (quando o mouse entra na área do saldo) e mouseleave (quando o mouse sai) para mostrar ou remover uma mensagem simples sem o uso de CSS.
    i. O evento mouseenter dispara quando o mouse entra na área do saldo e exibe a mensagem "Saldo disponível".    ii. O evento mouseleave remove a mensagem quando o mouse sai da área do saldo.

Passo 4: Testar o Projeto

1. Abra o arquivo index.html no navegador:
Use o navegador para testar o projeto. Você pode abrir o arquivo clicando duas vezes nele ou arrastando-o para o navegador.
2. Teste a funcionalidade:
Digite um valor no campo "Adicionar Dinheiro" e clique em "Adicionar".
Verifique se o saldo é atualizado na tela.
Passe o mouse sobre o saldo para ver a mensagem "Saldo disponível" aparecer e desaparecer.
