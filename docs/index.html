Aprendizado conectado

O mesmo raciocínio aparece em várias disciplinas

Quando você reconhece essas relações, os conceitos deixam de parecer isolados.

01

Lógica organiza o pensamento

Uma receita é um algoritmo: possui entradas, uma sequência de passos e um resultado.

entrada → processo → saída
→
02

HTML organiza a informação

As tags descrevem o papel de cada conteúdo e criam a estrutura da página.

<estrutura>conteúdo</estrutura>
→
03

CSS comunica visualmente

Cores, espaços e tamanhos ajudam o usuário a entender o que é mais importante.

seletor { propriedade: valor; }
→
04

JavaScript adiciona comportamento

Eventos transformam ações do usuário em mudanças visíveis na interface.

evento → função → resposta

Um método para cada desafio

Leia, planeje, construa e explique

  1. Leia o enunciado. Marque o que precisa existir no resultado.
  2. Planeje a menor solução. Divida o problema em partes pequenas.
  3. Construa e teste. Faça uma parte funcionar antes de avançar.
  4. Explique com suas palavras. Se você consegue explicar, está aprendendo.
💡

Desafio de revisão

Faça três perguntas ao seu código

  • O que entra?
  • O que acontece?
  • O que aparece no final?

Essas perguntas funcionam em Python, HTML, CSS e JavaScript.

Ajuda rápida

Como abrir e executar os projetos

Projetos HTML e CSS

Abra o arquivo index.html da aula no navegador. No VS Code, você também pode usar a extensão Live Server.

HTML1/Aula03/index.html
Exercícios JavaScript

Projetos que usam somente o terminal podem ser executados com Node.js.

node JS-1/Project3.js
Desafios de Lógica em Python

Com o Python instalado, execute o arquivo desejado pelo terminal.

python "Lógica/Desafio5.py"
Onde encontro o enunciado?

Os arquivos de enunciados ficam na raiz do repositório. O código de cada projeto também possui comentários explicativos.
